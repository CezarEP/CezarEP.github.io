Coleta automática e painel de moderação de comentários

Campanha ao Governo de Rondônia · ago–out 2026

45 min → 40 sciclo para publicar alterações no painel de moderação

Problema

A equipe conferia comentários do Instagram e do Facebook publicação por publicação. Não sabia quantos havia, quais estavam sem resposta nem onde estava a crítica.

O que eu fiz

  • Desenvolvi um pipeline em Python integrado à Graph API da Meta, com execução agendada.
  • Coloquei no ar um painel de moderação com fila de prioridade, filtro de pendências e acesso controlado por equipe.
  • Cruzei as respostas registradas pela API com as respostas visíveis na rede para validar o indicador de atendimento.

Resultado

  • A primeira execução processou 279 publicações de 30 dias.
  • O ciclo para publicar alterações no painel caiu de 45 minutos para cerca de 40 segundos.
  • A análise mostrou que 31% das respostas não eram atribuídas pela API por saírem de outro perfil; o indicador de atendimento foi corrigido.

Tecnologias

  • Python
  • Meta Graph API
  • Execução agendada
  • Painel web
  • Controle de acesso
